# Mauricio Narváez Portfolio

Professional portfolio for a Junior Full Stack Developer focused on practical business software, clean code and product thinking while seeking a first stable full-time software role.

## Overview

This site presents three featured software concepts built around realistic operational needs:

- Logistics Suite
- MaintenanceHub
- DentalFlow

It also highlights formal studies, continuous learning and experience gathered in a dental clinic support environment.

The design intentionally avoids generic student-portfolio patterns and instead aims for a premium, dark SaaS-inspired presentation.

## Stack

- React
- Vite
- JavaScript
- CSS
- React Icons

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The portfolio is structured as a single-page app with smooth scrolling.
- Content is driven by data files in `src/data`.
- Public links are only included where they exist; unavailable destinations are shown honestly.
- The resume is available in `public/CV_Mauricio_Narvaez.pdf`.
